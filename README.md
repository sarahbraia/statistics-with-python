# Statistics with Python 

This repository contains my study notes and practical exercises on statistics, as part of my Data Science learning journey. All examples are implemented in Python using libraries such as `pandas`, `matplotlib`, `seaborn`, `scipy`, and `statsmodels`.

## Contents

1. **Measures of Central Tendency** – mean, median, mode.
2. **Measures of Dispersion** – variance, standard deviation, range.
3. **Probability Distributions**
   - T-Student
   - Poisson
   - Binomial
   - Chi-Square (χ²)
4. **Hypothesis Testing**
   - Z-test and T-test
   - Chi-Square test
   - ANOVA (Analysis of Variance)
   - p-value interpretation
